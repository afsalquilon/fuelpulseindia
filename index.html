GitHub Pages & Mobile App (PWA) Guide

Install on Phone or Laptop App Ready

Android (Chrome): Tap the browser menu (⋮) → Install app or Add to Home screen.

iPhone / iPad (Safari): Tap the Share icon → Add to Home Screen.

Laptop (Chrome / Edge): Click the Install icon in the right side of the address bar.

1. Publish Free on GitHub Pages (from your Laptop)

  1. Create a public GitHub repo (e.g., fuelpulse-india) and upload index.html, manifest.json, and sw.js.
  2. Go to Settings → Pages → Branch: main and click Save for free HTTPS hosting.
  3. Open the GitHub Pages URL on your phone and tap "Add to Home Screen"!

const CACHE_NAME = 'fuelpulse-india-v1';
const ASSETS = ['./', './index.html'];
self.addEventListener('install', e => e.waitUntil(caches.open(CACHE_NAME).then(c => c.addAll(ASSETS))));
self.addEventListener('fetch', e => e.respondWith(caches.match(e.request).then(r => r || fetch(e.request))));
